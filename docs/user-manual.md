# POS 使用說明書

> 適用版本：2026-05-17 `feature` 分支  
> 適用對象：收銀員、店長、門市主管、驗收人員  
> 主要入口：Web POS 收銀台

## 1. 系統入口

本系統目前以 Web POS 為主要可操作版本，Flutter Android App 為開發中版本。

| 環境 | 網址 |
|------|------|
| 標準本地 Frontend | `http://localhost:38082` |
| 目前本機 POS Frontend | `http://localhost:38182` |
| 標準本地 Backend | `http://localhost:38080` |
| 目前本機 POS Backend | `http://localhost:38180` |

目前本機因另一個 `financial-accounting` 專案佔用 `38080` / `38082`，所以 POS 暫時跑在 `38180` / `38182`。正式驗收或獨立啟動時，請優先使用需求文件指定的標準 port。

## 3. 登入與鎖定

1. 開啟 `http://localhost:38182/pos/login`。
2. 輸入 PIN：`1234`。
3. 登入成功後會進入收銀台。
4. 若工作階段過期、POS session 遺失，或直接開啟 `/pos/register`，系統會自動導回 PIN 登入頁。
5. 點擊側邊欄的「鎖定終端」可登出目前 POS 工作階段，畫面會回到 PIN 登入頁。

## 4. 收銀台操作

### 4.1 加入商品

1. 進入「收銀台」。
2. 在商品清單點選商品卡片，商品會加入右側目前訂單。
3. 重複點選同一商品會增加數量。
4. 可使用分類按鈕快速切換商品類別。
5. 可使用搜尋欄輸入商品名稱、SKU 或條碼。

### 4.2 調整購物車

在右側「目前訂單」可操作：

| 操作 | 說明 |
|------|------|
| `+` | 增加該商品數量 |
| `-` | 減少該商品數量 |
| 刪除圖示 | 移除該商品 |
| 清空購物車 | 移除目前訂單所有商品 |

系統會即時計算小計、稅額、折扣與總計。

## 5. 會員操作

1. 在「目前訂單」點擊「會員」。
2. 輸入會員姓名、電話或會員編號搜尋。
3. 點選會員後，會員資訊會綁定到目前訂單。
4. 若會員有等級折扣，系統會自動套用會員折扣。
5. 即使之後改套手動折扣或促銷折扣，會員仍會保留在訂單中。
6. 若要移除會員，回到會員視窗並點擊清除會員。

## 6. 折扣與促銷

### 6.1 手動折扣

1. 點擊「折扣」。
2. 輸入折扣金額。
3. 確認後，系統會以手動折扣重新計算總額。

### 6.2 促銷折扣

1. 點擊「折扣」。
2. 可輸入優惠碼並套用。
3. 系統也會在符合規則時自動試算最佳促銷。
4. 促銷折扣會保留促銷名稱、優惠碼與規則資訊，結帳後可在訂單紀錄查看折扣來源。

### 6.3 折扣規則說明

目前折扣來源採互斥邏輯：

| 折扣來源 | 說明 |
|----------|------|
| 會員折扣 | 由會員等級折扣產生 |
| 手動折扣 | 收銀員手動輸入折扣金額 |
| 促銷折扣 | 由促銷規則或優惠碼產生 |

會員資料與折扣來源是分開保存的；改用促銷折扣不會移除會員。

## 7. 掛單與取單

### 7.1 掛單

1. 目前訂單有商品時，點擊右側上方「掛單與取單」。
2. 選擇掛單。
3. 系統會保存目前商品、會員、折扣、金額與桌號資訊。
4. 掛單後，目前購物車會清空，可繼續下一筆訂單。

### 7.2 取回掛單

1. 點擊「掛單與取單」。
2. 從列表選擇要取回的掛單。
3. 系統會將商品、會員與折扣資訊恢復到目前訂單。
4. 取回後可繼續修改商品或進行結帳。

## 8. 現金結帳

1. 確認目前訂單商品與金額。
2. 點擊「立即結帳」。
3. 進入結帳頁後，預設付款方式為現金。
4. 在「收款金額」輸入實收金額。
5. 若收款不足，系統會提示不足並禁止付款。
6. 金額足夠時，點擊「確認付款方式」。
7. 付款完成後，系統會顯示付款完成摘要、訂單號、商品、會員、折扣、應收與找零。
8. 付款完成後付款按鈕與收款欄位會鎖定，避免重複付款。
9. 可選擇「返回收銀台」或「查看訂單列表」。

目前已完成現金支付閉環。信用卡、LINE Pay、街口支付、悠遊卡等多支付方式 UI 已存在，但正式金流串接仍屬後續項目。

## 9. 訂單列表

1. 點擊側邊欄「訂單列表」。
2. 可查看完成訂單、付款狀態、發票狀態與金額。
3. 可使用訂單編號搜尋。
4. 點擊訂單可查看明細、付款記錄、發票與折扣稽核資訊。
5. 點擊「新增訂單」會回到收銀台開始新訂單。

## 10. 退款處理

1. 進入「退款處理」。
2. 選擇要退款的訂單。
3. 輸入退款原因並建立退款。
4. 完成退款後，訂單狀態與發票狀態會同步更新。
5. 全額退款會作廢對應 mock invoice。

退款功能目前支援基本閉環；正式營運前仍需補更多權限、審計與異常流程。

## 11. 商品管理

在「商品管理」與「分類管理」可維護商品與分類資料。

常見用途：

| 頁面 | 用途 |
|------|------|
| 商品管理 | 查看與維護商品名稱、價格、SKU、條碼、是否可銷售 |
| 分類管理 | 建立與整理商品分類 |

正式導入前，變體、套餐、Modifier、批次匯入仍需進一步正式化。

## 12. 庫存管理

在「庫存」區域可查看門店庫存與進貨驗收。

目前已支援：

| 功能 | 說明 |
|------|------|
| 庫存總覽 | 查看商品目前庫存 |
| 進貨驗收 | 建立入庫或驗收資料 |
| 收銀扣庫 | 訂單完成後自動扣減追蹤庫存商品 |
| 庫存不足攔截 | 庫存不足時阻止付款完成 |

盤點、調撥、完整異動查詢與補貨流程仍屬後續正式化項目。

## 13. 發票管理

在「發票」區域可查看 mock invoice。

目前流程：

1. 訂單完成後，系統自動建立 mock invoice。
2. 發票稅額會與訂單稅額一致。
3. 退款完成後，對應發票會作廢。

正式上線前仍需串接真實電子發票字軌、Turnkey 與上傳錯誤補償。

## 14. 會員管理

在「會員」頁可查詢會員、建立會員、查看點數與調整點數。

目前已具備基礎 CRM 能力：

| 功能 | 說明 |
|------|------|
| 會員查詢 | 依姓名、電話或會員編號搜尋 |
| 建立會員 | 建立基礎會員資料 |
| 點數流水 | 查看會員點數紀錄 |
| 點數調整 | 手動增加或扣減點數 |

儲值、完整消費歷程、會員停用/編輯與完整權限審計仍需後續補強。

## 15. 班次與對帳

### 15.1 班次

在「班次」頁可處理開班、關班與 X/Z 報表。

常見流程：

1. 開班並輸入開班現金。
2. 進行收銀交易。
3. 現金交易會累計到班次與 cash drawer。
4. 關班時計算現金差異。

### 15.2 對帳

在「對帳」頁可查看每日現金交易彙總。

目前可驗證：

| 項目 | 說明 |
|------|------|
| 現金交易金額 | 來自 `pos_payment_transactions` |
| 訂單數 | 當日完成訂單彙總 |
| 班次 / 錢櫃 | 與 cash drawer 事件串接 |

多支付方式、異常關班、完整日結報表仍屬後續項目。

## 17. 常見問題

### 17.1 為什麼我會被導回登入頁？

可能原因：

- PIN session 已遺失。
- JWT 已過期。
- 手動鎖定終端。
- 直接開啟 `/pos/register` 但尚未登入。

重新輸入 PIN `1234` 即可。

### 17.2 商品載入失敗怎麼辦？

請確認：

1. Backend container 是否啟動。
2. Frontend 是否指向正確 backend。
3. POS session 是否有效。
4. 本機 port 是否被其他專案佔用。

目前本機 POS 暫跑：

```text
Frontend: http://localhost:38182
Backend:  http://localhost:38180
```

### 17.3 會員套促銷後不見了怎麼辦？

目前已補回歸測試，正常情況下會員不會因套用手動折扣或促銷折扣而消失。若畫面異常，請回到會員按鈕確認是否仍顯示會員名稱。

### 17.4 結帳後可以再改收款金額嗎？

不行。付款完成後付款方式、收款金額與付款按鈕會鎖定，避免重複付款或改動已完成訂單。

## 18. 驗收建議流程

建議用以下流程快速驗收系統：

1. 開啟 `http://localhost:38182/pos/login`。
2. PIN 登入 `1234`。
3. 加入「美式咖啡 12oz」與「拿鐵 12oz」。
4. 綁定會員。
5. 套用折扣或促銷。
6. 掛單。
7. 取回掛單。
8. 進入結帳。
9. 輸入足額現金並完成付款。
10. 查看付款完成摘要與找零。
11. 到訂單列表搜尋該訂單。
12. 查看付款記錄與發票狀態。
13. 執行退款。
14. 回到發票頁確認發票作廢。
