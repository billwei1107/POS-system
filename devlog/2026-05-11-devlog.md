## 問題紀錄 (Issues)

- 第一次 Docker 重建使用錯誤 compose 路徑，導致前端容器仍是舊 bundle，付款時送出 `113.40` 並產生 `change_given=0.40`。
- 正確流程是只重建並重啟 frontend：`docker compose -f docker/local/docker-compose.yml build frontend`，再 `docker compose -f docker/local/docker-compose.yml up -d --no-deps frontend`。
- `docker compose ... up -d --build frontend` 會因 `depends_on: backend` 嘗試重建 backend；若 Docker 內 Maven DNS 暫時無法解析 `repo.maven.apache.org`，會讓 frontend 更新被 backend build 失敗擋住。
