## 問題紀錄

### 後端編譯失敗根本原因
- **現象**: `module-workflow`/`module-notification` 編譯時 `cannot find symbol`（Lombok-generated getters/setters）
- **根本原因**: Maven 的 JVM 是 `/opt/homebrew/Cellar/openjdk/25.0.2`（Java 25），但 Lombok 1.18.30 不支援 Java 25。`TypeTag::UNKNOWN` 是 Lombok 在 Java 25 環境下初始化失敗的錯誤。
- **解決方案**:
  1. 父 pom.xml 加入 maven-compiler-plugin 3.13.0 + annotationProcessorPaths（Lombok 1.18.32）
  2. `~/.zshrc` 補 `export JAVA_HOME="/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home"`
  3. 臨時指令加 `JAVA_HOME=... mvn ...` 前綴
- **注意**: 新開 terminal 後 `JAVA_HOME` 才會生效，本 session 仍需加前綴

### tsconfig baseUrl 棄用
- **現象**: TypeScript 6 把 `baseUrl` 標記為 deprecated，`--ignoreDeprecations` 的值格式也變了
- **解決方案**: 改用 `paths` 直接寫絕對路徑前綴（`./src/shared/*`），不依賴 `baseUrl`
