#### 關鍵設計決策（Sprint 2-2）

- **X Report 不重置**：`XReportCalculator.generate()` 直接讀取 StaffShift 累計欄位快照，不清空計數器，可在班次中多次呼叫
- **Z Report 防篡改 Hash**：`ZReportCalculator.computeHash()` 將 storeId / reportDate / totalSales / totalRefunds / totalTax / netSales / cashInDrawer / transactionCount 用 `|` 串接後 SHA-256 雜湊，`verifyHash()` 可隨時驗證完整性
- **盲點結算（Blind Close）**：`blindCloseShift()` 不要求現金清點，狀態改為 `BLIND_CLOSED`，適用於快速結班場景
- **班次統計事件累計**：`StaffEventListener` 消費 `OrderCompletedEvent` 累計 totalSales / transactionCount，`RefundCompletedEvent` 累計 totalRefunds，`OrderVoidedEvent` 遞減 transactionCount
- **Z Report 每日唯一**：`ZReportRepository.findByStoreIdAndReportDate` 配合 DB unique index 確保同一門店同一日只有一張 Z Report
