## Admin Sidebar Icon Semantics Polish

- 時間：2026-05-21 11:13:04 CST。
- 目標：修正後台側邊欄收合後多個項目圖標輪廓相同，造成使用者必須靠 tooltip 猜測功能的問題。

## Planning - Admin Sidebar Icon Semantics Polish

- 原則：
  - 同一功能群內的相鄰項目不得使用相同圖標。
  - 收合狀態下仍需可透過圖標輪廓快速區分常用功能。
  - tooltip 保留為輔助，不作為主要辨識手段。
- 優先處理截圖中最明顯重複的群組：
  - POS 管理：商品、分類、訂單、退款。
  - 庫存：庫存、進貨、盤點、調撥。
  - 營運：發票、字軌、稅別、班次、報表、對帳、支付、金流。
  - 組織、權限、人事也同步避免使用同一輪廓。

## Progress - Admin Sidebar Icon Semantics Polish

- `AdminLayout`：
  - `分類管理` 改用 `CategoryIcon`。

  - `班次管理`、`Z 報表`、`對帳`、`金流設定` 分別改用 `ScheduleIcon`、`AssessmentIcon`、`BalanceIcon`、`SettingsSuggestIcon`。
